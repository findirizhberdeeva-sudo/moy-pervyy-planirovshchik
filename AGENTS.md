# Напоминание при следующем возвращении к проекту

По просьбе пользователя от 1 ноября 2026 года в начале следующей рабочей сессии над этим проектом кратко напомни о пожеланиях из раздела «Доработки на следующее возвращение к проекту» в `plan.md`:

- наглядная динамика выполнения задач Светланы;
- поддерживающие сообщения по результатам рабочего дня.

Не повторяй напоминание в каждом сообщении текущей сессии и не создавай календарное расписание: пользователь попросил напомнить при возвращении к проекту, без даты. После показа напоминания отметь это в указанном разделе `plan.md`, чтобы не дублировать его в следующих сессиях. Пока отметка показа отсутствует, напоминание остаётся актуальным.

Это пожелания на следующую доработку, а не уже реализованные возможности. Перед реализацией сверь `tz.md` и `plan.md`, уточни невыбранные правила сообщений. Не начинай писать код только на основании этой заметки.
